# خريطة وحدات المشروع

كل المسارات نسبة إلى `iraq-platform/`. نقطة دخول الخادم الواحدة: `functions/api/[[path]].js` (تنادي الوحدات بالترتيب). لا إعادة هيكلة مجلدات؛ هذه خريطة لتطوير كل وحدة في جلسة مستقلة.

| الوحدة | الملفات الأساسية | مسارات API | تعتمد على | أهم مشكلة متبقية |
|---|---|---|---|---|
| **Core** | `functions/_lib/auth.js`، `scope.js`، `authz.js`، `authz_bridge.js`، `migrate.js`، `migrations/*.sql`، `functions/_middleware.js`، `site/js/auth.js`، `site/login.html` | `/api/auth/*`، `/api/sync` | — | `scope.js` ينشئ الجداول وقت التشغيل (`ensureScopes`) بجانب ملفات الترحيل: مصدران للمخطط. |
| **University Catalog** | `functions/_lib/catalog.js`، `onboarding.js`، `functions/api/platform.js`، `site/catalog.html`، `join.html`، `dept.html`، `stage.html`، `subject.html`، `site/data/courses.js` | `/api/catalog/*`، `/api/platform`، `/api/admin/universities*` | Core | طالب جامعة غير مفعّلة لا يُبلَّغ عند التفعيل؛ عليه إعادة الدخول ليُفتح قسمه. |
| **Admin Dashboard** | `functions/_lib/global-admin.js`، `admin-workspace.js`، `onboarding.js`، `site/admin.html`، `admin-tools.html`، `site/js/admin-v3.js` | `/api/admin/workspace`، `/api/admin/universities/overview`، `/api/admin/universities/analytics`، `/api/auth/users`، `/api/auth/global-admins` | Core، Catalog، Content | لا قياس نشاط فعلي: «دخلوا آخر ٧ أيام» = تسجيل دخول فقط. جدولا `files` و`reports` في D1 غير مستعملين. |
| **Student Dashboard** | `site/platform.html`، `semester.html`، `course.html`، `site/js/app.js`، `nav.js`، `i18n.js` | `/api/platform`، `/api/catalog/me`، `/api/stage-announcements` | Core، Catalog، Notifications | `data/courses.js` يحمّل القسم بطلب متزامن (XHR sync) يجمّد الصفحة على الشبكات البطيئة. |
| **Representatives** | `functions/_lib/rep_assignments.js`، `rep_lifecycle.js`، `admin-workspace.js` (المرحلة)، `site/representatives.html`، `team.html`، `manage.html`، `site/js/representatives.js` | `/api/auth/scope(s)`، `/api/auth/rep-request*`، `/api/admin/stage-representative`، `/api/admin/stage-students` | Core، Catalog | بعد P0.3 الطالب غير المؤكَّد لا يرى إعلانات مرحلته: يلزم تنبيه للممثل بوجود طلاب بانتظار التأكيد. |
| **Content Manager** | `netlify/lib/core.mjs`، `functions/_lib/kvstore.js`، `site/upload.html`، `contribute.html`، `site/js/upload*.js` | `/api/uploads`، `/api/file/<id>`، `/api/finish`، `/api/link`، `/api/edit`، `/api/delete`، `/api/reports` | Core، Catalog (KV: `LECTURES`) | القائمة كلها في مفتاح KV واحد (`manifest.json`) بكتابة غير ذرّية؛ حد الملف 20 ميغا. |
| **PDF Studio** | `site/pdf-notes.html`، `site/js/studio-*.js`، `pdf-sync*.js`، `site/css/studio*.css`، `functions/_lib/pdfnotes.js` | `/api/pdfnotes`، `/api/pdfnotes/asset` | Core، Content | مكتبة pdf.js تُحمَّل من cdnjs: تتعطل الصفحة إن حُجب. |
| **AI Assistant** | `functions/_lib/study_assistant.js`، `study_dept.js`، `ai.js`، `functions/api/study-assistant/*`، `site/study-assistant.html`، `site/js/study-assistant*.js`، `ai-chat.js`، `ai-guide.js` | `/api/study-assistant/*`، `/api/ai/*` | Core، Catalog، PDF Studio (ربط `AI`) | لم يُجرَّب مع Workers AI الحقيقي؛ جودة الإجابات وحدود الحصة غير مقيسة. |
| **Group Chat** | `functions/_lib/group_chat.js`، `group_chat_moderation.js`، `site/group-chat.html`، `group-chat-admin.html`، `site/js/group-chat*.js` | `/api/group-chat/*` | Core، Representatives | يعتمد على استطلاع دوري (لا رسائل لحظية). |
| **Study Tools** | `site/study.html`، `site/js/study-*.js`، `anki-scheduler.js` | — (تخزين محلي + `/api/sync`) | Core، PDF Studio | ملفات بإصدارات متراكمة (`v82…v92`) بلا توثيق لما هو مستعمل فعلاً. |
| **Notifications** | `functions/_lib/auth.js` (التبليغات العامة)، `announcement_audience.js`، `notify_events.js`، `admin-workspace.js` (إعلانات المرحلة)، `site/announce.html`، `site/js/announce.js` | `/api/announcements`، `/api/announcements/delete`، `/api/admin/stage-announcements`، `/api/stage-announcements` | Core، Representatives | لا إشعارات دفع؛ `announcement_audience.js` (عزل الجمهور بالنطاق) منطق غير موصول بجدول `announcements`. |
| **Mobile/PWA** | `site/sw.js`، `site/manifest.webmanifest`، `site/assets/icon-*.png` | — | كل الصفحات | رقم الإصدار `V` في `sw.js` يُرفع يدوياً؛ نسيانه يُبقي ملفات قديمة عند المستخدمين. |
| **Growth** | `functions/_lib/invites.js`، `onboarding.js` (analytics)، `migrations/0014_invites_growth.sql` | `/api/invite`، `/api/admin/invites`، `/api/admin/universities/analytics` | Core، Catalog | التحليلات تعدّ التسجيلات فقط؛ لا تتبّع للاحتفاظ أو مصدر الزيارة خارج روابط الدعوة. |
