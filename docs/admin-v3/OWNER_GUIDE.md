# دليل مراجعة لوحة الإدارة

## مراجعة الفرع

ملف `admin-v3-checkpoint.bundle` يحفظ نقاط تقدم الفرع. يمكن استعادته داخل نسخة محلية من مستودع `universitiesofiraq-web/iraq-platform` تحتوي على التعديل `84105f1`. استخدم مسار الملف الذي نزّلته.

```bash
git bundle verify /path/to/admin-v3-checkpoint.bundle
git fetch /path/to/admin-v3-checkpoint.bundle \
  refs/heads/feature/admin-v3-onboarding-rbac:refs/heads/feature/admin-v3-onboarding-rbac
git switch feature/admin-v3-onboarding-rbac
node --test iraq-platform/tests/*.test.mjs tests/*.test.cjs
```

إذا أردت دفع نقطة الاستعادة من جهاز مرتبط بـGitHub، ارفع الفرع وحده.

```bash
git push -u origin feature/admin-v3-onboarding-rbac
```

## تجهيز معاينة معزولة

1. تحقق من أن إعدادات معاينة Cloudflare Pages تستخدم D1 وKV منفصلين عن الإنتاج وأنها محمية من الزوار غير المقصودين. بعض إعدادات Pages تنشئ معاينة تلقائيًا عند رفع الفرع.
2. طبّق الترحيلات 0008 إلى 0010 على قاعدة المعاينة بالترتيب، بعد الترحيلات 0001 إلى 0007. حافظ على `ADMIN_EMAILS` لحسابات المالك، واضبط بيانات اعتماد تسجيل الدخول للمعاينة على نحو مستقل.
3. راجع الدليل من حساب المالك. الوضع الافتراضي يعرض فقط الجامعات المسجلة والنشطة. افتح «كل جامعات الدليل» لتسجيل جامعة جديدة.
4. أضف الجامعة أو راجع ملفها. عيّن حسابًا نشطًا مسؤولًا على نطاق الجامعة من «الكليات والأقسام والتعيينات». اختر الجامعة، ثم «تسجيل»، واختر المسؤول.
5. افتح «المسجلة غير المفعّلة». راجع بيانات الجامعة واختر «اعتماد التحقق»، ثم «تفعيل». اختبر ظهورها للطالب وإخفاءها بعد «تعليق».
6. ادخل إلى نطاق كلية أو قسم من زر «إدارة الجامعة» أو من حساب المسؤول المعيّن. افتح بطاقة المرحلة، وعيّن ممثلًا ببريد حسابه. استخدم «استبدال الممثل» عند الحاجة.
7. من لوحة المرحلة بحساب مسؤول أعلى، اربط حساب الطالب من «طلبة المرحلة» بعد التحقق من انتمائه. يمكن للممثل رؤية الأسماء المرتبطة ونشر إعلان للمرحلة. لا تمنح الصفحة للطالب عضوية بناءً على تغيير اختياره في المتصفح.
8. افتح صفحة الإدارة بحساب الممثل. اختبر رفع ملف صالح ومراجعته، ثم جرّب تغيير معرّف المرحلة في الرابط وفتح ملف معلّق خارج النطاق. راجع عرض الهاتف والكمبيوتر ولوحة المفاتيح.

## الانتقال والتراجع

- راجع قائمة الجامعات المشاركة فعليًا قبل نشر أي إصدار يُطبق فلتر العضوية. الترحيل لا يفعّل أي صف تلقائيًا. تحقّق أيضًا من تمثيل الكليات الطبية ذات الأقسام القديمة المسماة باسم مرحلة. استخدم نطاق الكلية عند الحاجة لرؤية جميع أقسامها. لا تعِد ربط مراحلها القديمة قبل مراجعة خريطة البيانات.
- راجع حالة ربط الطلبة بالمراحل قبل الاعتماد على الإعلانات المخصصة. يحتفظ النظام بالإعلانات العامة ويضيف إعلانات المرحلة للحسابات المرتبطة فقط.
- عند التراجع، اترك الترحيلات وبيانات التدقيق. في حال وجود ملفات رُفعت بعد الانتقال، يجب الاحتفاظ بقارئ الملفات الذي يدعم `chunkPrefix` حتى تظل قابلة للفتح. لا تعد إلى قارئ أقدم قبل تأمين تلك الملفات. راجع كذلك الرفع الذي كان جاريًا لحظة الانتقال.
- مخزن KV الحالي يحاكي الكتابة المشروطة وليس معاملة ذرية. تتطلب عمليات الرفع المتزامنة ومراجعة الملف اختبار ضغط على بيئة معاينة قبل الإنتاج. لا تحذف القطع المحفوظة اعتمادًا على عمرها لأن بعض الملفات المنشورة القديمة تُقرأ منها مباشرة.

## حدود التسليم

اجتازت الاختبارات المحلية 35 حالة معلنة. بقيت المعاينة في متصفح حقيقي والتقاط صور اللوحات واختبار تسجيل الدخول والرفع على Pages. لا يتضمن الفرع دردشة مرحلة أو مسار طلبات انضمام طلابي جديدًا. تعطّل رفع الفرع وفتح Draft PR بسبب رفض صلاحية الكتابة في اتصال GitHub. لم تُنفّذ عمليات إنتاجية.
