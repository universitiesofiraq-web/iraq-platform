# المنصة العراقية (اسم مؤقت)

منصة لملفات المواد الدراسية لجامعات وكليات العراق. منسوخة من كود موقع جامعة واحدة **بدون** أي ملفات أو بيانات أو مفاتيح أو درجات طلاب.

## الحالة
- الكود يعمل كقاعدة: دخول Google، أدوار، رفع ملفات، تبليغات (Cloudflare Pages Functions + D1 + KV).
- `migrations/0003_multi_university.sql` يضيف هيكل جامعة > كلية > قسم > مرحلة > كورس > مادة > ملف، وحالة موافقة للملفات، ونطاق أدوار لكل كلية، وجدول التبليغات.
- **لم يُربط بعد**: الواجهة والدوال ما زالت تقرأ `site/data/courses.js` (مواد وكورسات) ولا تستعمل جداول 0003. هذه المرحلة التالية.

## التشغيل على حساب Cloudflare الجديد
1. أنشئ مشروع Pages مربوطاً بمستودع GitHub (مجلد النشر: `site`).
2. أنشئ قاعدة D1 باسم `DB` فقط. الترحيلات في `migrations/` تُطبَّق تلقائياً عند أول طلب API بعد كل نشر (`functions/_lib/migrate.js`).
   - عند إضافة ملف ترحيل جديد: شغّل `node scripts/gen-migrations.mjs` ثم ارفع الناتج مع الملف (اختبار `tests/migrate.test.mjs` يفشل إن نسيت).
   - اجعل كل جملة `IF NOT EXISTS` حتى تُعاد بأمان.
3. أنشئ KV وربطه باسم `LECTURES`.
4. أضف المتغيرات: `GOOGLE_CLIENT_ID`، `ADMIN_EMAILS`، `UPLOAD_CODES` (أسرار بيدك فقط).
5. أنشئ مشروع Google Cloud جديداً لتسجيل الدخول وأضف رابط الموقع الجديد.

## قبل النشر
- صفحتا `privacy.html` و`terms.html` ورثتا من الموقع القديم: راجعهما.
- الترجمات الإنجليزية والفارسية في `i18n.js` و`login-i18n.js` تحتاج مراجعة بعد تغيير النصوص.
